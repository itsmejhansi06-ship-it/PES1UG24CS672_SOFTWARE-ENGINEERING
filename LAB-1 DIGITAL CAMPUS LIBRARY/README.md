## Objective

The objective of this lab is to identify and document the requirements of a **Digital Campus Library** system and represent its functionality using a Use Case Diagram and Use Case Flow.

## Contents

This folder contains:

1. **Use Case Diagram**
   Shows the actors and their interactions with the Digital Campus Library system.

2. **Requirements**
   Contains the functional and non-functional requirements of the system.

3. **Use Case Flow**
   Describes the steps involved in the different use cases.
